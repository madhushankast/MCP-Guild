# MCP Guild

Welcome to the official repository for the **MCP Guild**!

This repository serves as the central hub for our guild activities, projects, and learning resources.

## 🚀 Getting Started

This project uses [**pnpm**](https://pnpm.io/) for package management.

1.  Install pnpm:
    ```bash
    npm install -g pnpm
    ```

2.  Install dependencies:
    ```bash
    pnpm install
    ```

3.  Run the project:
    ```bash
    pnpm run dev
    ```
